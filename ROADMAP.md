## Role

Quartz is the display layer. Content comes from `my-wiki` via `deploy.yml`. This repo has no active feature development — it only changes when visual config, theme, or layout needs to be updated.

---

## Planned Changes

None currently. Quartz is working as intended.

If visual changes are needed in the future, they would be:
- Theme updates (`quartz.config.ts` — colors, fonts)
- Layout changes (`quartz.layout.ts` — sidebar, header components)
- Custom CSS overrides (`quartz/styles/custom.scss` if it exists)

**Do not touch `content/` directly.** It is auto-generated by `my-wiki/deploy.yml`.

---

## If You're Here to Change Something

1. Run `npx quartz build --serve` locally to preview before committing.
2. Changes to `quartz.config.ts` or `quartz.layout.ts` go here.
3. Changes to what gets published (which notes, what metadata) go in `my-wiki/` — specifically `CLAUDE.md`, `.quartzignore`, or `deploy.yml`.
4. Log any config changes in `my-wiki/00-Meta/CHANGELOG.md`.
