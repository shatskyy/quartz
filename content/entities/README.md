# Entity Index

This folder contains pages for specific people, organizations, and named tools that appear across multiple notes in the wiki. Entity pages are progressively enriched: each new source that mentions an entity should update its page rather than duplicate information elsewhere.

## Promotion threshold

An entity gets its own page when it is mentioned substantively in at least two separate sources. Before that point it may be referenced inline in concept notes but does not have a dedicated page.

## Page structure

Each entity page follows the standard note format with these recommended sections:

- **Summary** — one paragraph overview
- **Claims** — notable facts, quotes, or positions attributed to this entity
- **Timeline** — dated events or mentions
- **Related Concepts** — wikilinks to concept notes where this entity appears
